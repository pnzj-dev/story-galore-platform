# Naming

## Product name: StoryGalore

**StoryGalore** is the working product name for the expanded creator-media platform. It communicates stories moving across formats rather than tying the brand to comics alone.

Use **StoryGalore** in product/UI copy and package scopes unless a legal/domain/trademark review changes the name.

### Naming guardrail

This is a product naming decision, not a trademark clearance. Before public launch, perform formal trademark, company-name, social-handle, app-store and domain checks in the target markets. Do not claim the name is legally available based on a web search alone.

### Product language

- StoryGalore — platform
- StoryGalore Reader — public consumption experience
- StoryGalore Studio — creator workspace
- StoryGalore Admin — protected operations/admin route surface within the single Astro application
