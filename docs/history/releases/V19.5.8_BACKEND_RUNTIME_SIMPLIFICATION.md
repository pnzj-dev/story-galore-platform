# V19.5.9 Backend Runtime Simplification

## Decision

StoryGalore uses **Go as the mandatory backend language wherever technically supported**.

This is an architectural determinism rule, not a workload preference.

### Backend

- Appwrite Functions: Go
- Backend services: Go
- Backend workers: Go
- Backend CLI/operations: Go
- Backend libraries: Go
- Backend integrations: Go

### Explicit platform exceptions

TypeScript remains only where the platform runtime requires it:

- Cloudflare Workers
- Cloudflare Agents SDK
- Cloudflare MCP Worker

### Frontend

Astro/Svelte/browser code remains TypeScript/JavaScript.

### Deterministic rule

A coding agent MUST NOT select a backend language.

If a backend executable is not Go and is not listed as a registered platform exception, implementation MUST BLOCK.

This removes runtime choice while preserving the minimum language required by platform boundaries.
