# V19.5.9 — Backend Runtime Simplification

## Decision
V19.5.9 supersedes this runtime decision: all backend execution uses Go except explicitly registered Cloudflare platform runtimes.

## Why this preserves functionality
- Function boundaries remain unchanged.
- Function IDs, contracts, triggers, schedules, permissions, resource maps and test matrices remain unchanged.
- Only the implementation runtime is standardized.
- Cloudflare Workers/Agents/MCP are already TypeScript-oriented, so shared validation, types, tooling and CI become simpler.

Appwrite supports Node.js and Node.js TypeScript Function templates and runtime selection.

## Deliberately not merged
The 27 logical Function contracts remain separate because several have materially different triggers, schedules, security scopes, scaling profiles or external-provider failure characteristics. Merging them would reduce deployment count but increase coupling and blast radius.
