# V18.7 — AI Credit Boundary & Media Provider Expansion

## V1 rule
Creator Studio credits are only for StoryGalore-managed AI models explicitly marked credit-eligible. BYOK and user-hosted/self-hosted AI never consumes StoryGalore credits.

## Enforcement
The server-side Policy Engine evaluates billing mode, provider ownership, execution location and model eligibility before any credit command. The UI is not authoritative.

## Media providers
The provider registry now has a first-class media family. Higgsfield is included as a provider adapter with a dynamic catalog because its official API aggregates many image/video models. Model IDs and schemas must be refreshed from official provider documentation and must not be hard-coded as the permanent catalog.

## Cost separation
StoryGalore-managed provider spend, creator credit consumption, BYOK provider charges and user-hosted operational costs are separate accounting dimensions. BYOK charges must never be represented as StoryGalore credit usage.
