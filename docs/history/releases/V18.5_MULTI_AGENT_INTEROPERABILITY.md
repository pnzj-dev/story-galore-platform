# V18.5 — Multi-Agent Interoperability & Agent Platform

## V1 decision

All advanced agents previously considered V1.5 are now **V1 agents**. V1 includes the native Cloudflare Agent family plus external-agent interoperability.

All are Cloudflare Agents. The Orchestrator coordinates them but does not bypass domain authorization.

## External agents

External Claude, ChatGPT/Codex, Grok, DeepSeek, Gemini, user-hosted agents and other compatible agents connect through the Agent Gateway. MCP is the primary capability interface; A2A-compatible transport is supported through an adapter boundary. Provider-specific logic must not leak into domain code.

## Security boundary

Agents receive scoped capabilities, tenant/resource scope, expiration, budget and a policy decision. They never receive Appwrite, Cloudflare, payment, database, or BYOK secrets. Trust level is metadata; capability authorization is authoritative.

## Coding / Dev Agent

GitHub is the engineering control plane for V1. StoryGalore Support remains customer-facing. A support escalation can create a canonical GitHub Issue. Coding agents operate on isolated branches, run the deterministic validation pipeline, create a PR with evidence, and stop at `DEPLOYMENT_CANDIDATE` unless a separate deployment policy authorizes staging/production.

### Bug-to-deployment lifecycle

```text
Support Ticket / GitHub Issue
        -> Agent Task
        -> Recon
        -> Reproduce
        -> Plan
        -> Implement
        -> Regression Tests
        -> Contract + Security Validation
        -> Build
        -> Draft PR
        -> QA / Release Agent
        -> Staging Candidate
        -> Staging Verification
        -> DEPLOYMENT_CANDIDATE
        -> explicit deployment approval
        -> production
```

The agent's claim is never the source of truth. CI, policy, deployment, Appwrite and operational systems are authoritative for their respective facts.

## CEO and Data Analysis agents

The CEO Agent is advisory: it can synthesize authorized reports, risks, KPIs and scenarios, but cannot self-authorize production or financial changes. The Data Analysis & Reporting Agent produces deterministic reports from authorized analytics/operational sources and preserves metric definitions and query provenance.
