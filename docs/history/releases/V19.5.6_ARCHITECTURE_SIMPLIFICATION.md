# V19.5.6 — Architecture Simplification

## Objective
Preserve StoryGalore V1 functionality while reducing independently operated execution boundaries.

## Decisions

1. **Cloudflare Workflows is the sole V1 durable execution engine.**
2. **Appwrite TablesDB is authoritative domain/operation state, not a second job executor.**
3. **Appwrite Functions remain for synchronous handlers, webhooks, schedules, and integrations.**
4. **The MCP runtime boundary is the Cloudflare stateless MCP Worker; the old backend/cloudflare/mcp placeholder is removed.**
5. **Temporal artifacts and legacy non-executable agent directories are removed.**
6. **DocumentsDB and VectorsDB remain because they provide capabilities not equivalent to TablesDB: schemaless document storage and vector similarity search.**
7. **No new database, queue service, cache service, or generic event bus is introduced.**

## Resulting runtime

```text
Astro / Appwrite Sites
        │
        ├── Appwrite Auth / TablesDB / DocumentsDB / VectorsDB / Storage
        ├── Appwrite Functions (sync + webhooks + schedules + integrations)
        │
        └── Cloudflare
             ├── Workers / MCP
             ├── Agents
             └── Workflows (all durable execution)

Bunny = deterministic media failover only
External providers = explicit adapters
```

## Deliberately retained boundaries

- TablesDB: transactional domain state
- DocumentsDB: genuinely schemaless payloads
- VectorsDB: similarity search
- Storage: binary media
- Cloudflare Workflows: durable execution
- Cloudflare Agents: reasoning/stateful agent runtime
- Cloudflare MCP Worker: external agent protocol boundary
- Bunny: secondary media distribution

These are retained because merging them would either remove a required capability or create a less deterministic substitute.

## Simplification loop result

The first loop removed the duplicate durable executor. A second audit found no additional runtime that can be removed without either deleting a required capability or conflating a distinct security/scaling boundary.
