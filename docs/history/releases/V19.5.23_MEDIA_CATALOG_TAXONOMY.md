# V19.5.23 — Media catalog taxonomy and mapping

This release adds `contracts/domain/media-catalog-taxonomy.yaml` as the canonical distinction between six user-facing catalog families and the existing publication/asset enums. Existing persistence enums are preserved. Shorts remains a derived VIDEO view; generic Books formats are capability-gated; Games remain catalog-only until a game-domain contract is approved. Category/genre examples are extensible and non-exhaustive.

Validation entry point: `pnpm validate:v19-5-23`. This is a repository-specification change, not a claim that the listed media capabilities are implemented or deployed.
