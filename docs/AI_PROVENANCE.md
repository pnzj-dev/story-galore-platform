# AI Provenance and IP Contract

Every consequential AI generation preserves provenance and never destructively replaces creator source material.

Minimum provenance includes:

- creator/workspace
- generation/job identifier
- provider and model identity/version when available
- execution location
- capability
- workflow/reference inputs
- transformation lineage
- policy decision/version
- billing mode and cost metadata
- timestamps
- resulting asset/draft revision identifiers

Credentials and secrets are never part of provenance, workflow history, analytics, or audit records.
