# ADR-0016 — V1 Social Core

## Decision
Adopt a creator-centric social graph with follows, posts, reactions, comments, mentions, collections, sharing, polls, notifications, moderation, block/mute controls and constrained 1-to-1 messaging.

## Rationale
StoryGalore's social loop is creator -> story -> community -> subscription -> sharing. Generic friends/groups/live/social-video features would increase scope without strengthening the core publishing loop.

## Non-goals
Friends, generic groups, livestreaming, voice rooms, short-form social video, large-scale gamification and social reputation are deferred.

## Security
Social exposure is subordinate to authentication, actor status, block/mute, publication, age, adult preference, entitlement, jurisdiction, moderation and Policy Engine decisions.
