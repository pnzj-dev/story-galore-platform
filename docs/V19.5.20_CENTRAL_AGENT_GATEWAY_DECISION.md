# V19.5.20 — Central Agent Gateway Decision

## Decision

The Central Agent Gateway is one Appwrite Function with stable ID `central-agent-gateway`. The Policy Engine is an in-process module within that function, not a second Appwrite Function, worker, or independently deployed service. A separate service requires an approved architecture decision record (ADR) backed by a demonstrated platform constraint.

All autonomous-agent calls that touch Appwrite MUST pass through this gateway and the registered Appwrite MCP connection. Agents MUST NOT call Appwrite SDKs, REST APIs, or native MCP tools directly.

## Deterministic request path

1. Authenticate the runtime invocation using a verified unattended identity mechanism.
2. Derive the canonical agent ID from trusted runtime identity and signed invocation context; never trust model-generated identity fields.
3. Validate the request against the gateway input schema and exact registered StoryGalore tool schema.
4. Resolve the stable StoryGalore tool ID through the versioned native-tool registry.
5. Evaluate the agent allowlist, capability registry, actor, tenant, resource scope, risk policy, and required approval.
6. Require an idempotency key for every mutation.
7. Invoke only the registered Appwrite MCP tool using the verified server authentication mode.
8. Validate and project the provider result against the registered output schema.
9. Emit a redacted audit record and return only the registered response shape.

Any unknown, ambiguous, unavailable, stale, unauthorized, or contradictory input fails closed. The gateway must never infer native tool names, resource IDs, permissions, or provider authentication semantics.

## Deployment and language

Use the official Appwrite CLI to generate the function scaffold. Go is the required backend language where the selected Appwrite Functions runtime officially supports it. Before generating the scaffold, resolve the latest stable compatible Appwrite CLI and Go toolchain versions from official sources and pin exact versions for that scaffold run. Do not hand-invent a generated directory layout.

## Explicit blockers — no runtime implementation is claimed

- Verify official Appwrite Go runtime support and resolve its exact latest stable compatible version.
- Verify an unattended Appwrite MCP identity mode, token lifetime/rotation, revocation, and least privilege.
- Capture and hash the official Appwrite MCP tool catalog and register each allowed native tool's exact schema, side effects, and scopes.
- Register exact canonical resource IDs for policy, approval, idempotency, audit, and tenant/domain authorization resources.
- Verify Appwrite Function timeout, request-size, execution, networking, and secret-injection limits against gateway needs.
- Pass all cases in `contracts/functions/test-matrix/central-agent-gateway.yaml`, including bypass, tenant isolation, revocation, idempotency, and secret-redaction tests.

Until all blockers are cleared, the function remains contract-only and deployment is prohibited.
