# Desktop Readiness

V1 must remain ready for a future desktop application.

Desktop may provide richer offline storage, filesystem access, drag-and-drop, keyboard shortcuts, local library management, system notifications, and application updates.

Desktop capabilities MUST be exposed through adapters. They MUST NOT move authorization or entitlement decisions into the desktop client.

Creator Studio is expected to benefit from desktop workflows such as asset management, bulk upload, editing, AI generation orchestration, and export.
