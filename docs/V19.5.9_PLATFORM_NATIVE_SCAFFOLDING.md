# V19.5.9 Platform-Native Scaffolding

Platform-managed project structure is generated by the platform's official CLI whenever an official scaffold/generator exists.

The coding agent MUST NOT invent or manually reproduce platform-specific directory layouts.

## Required flow

1. Resolve the StoryGalore component contract.
2. Resolve the pinned official scaffolder version and exact command/flags.
3. Generate the component using the official CLI.
4. Inspect the generated structure.
5. Register the generated structure.
6. Implement StoryGalore contracts within it.
7. Run platform validation.
8. Run global deterministic validation.

## Platform tooling

- Astro → Astro CLI
- Appwrite Sites/Functions → Appwrite CLI
- Cloudflare Workers/Agents/Workflows/MCP → Wrangler
- Go modules/workspaces → Go tooling

This policy does not eliminate StoryGalore's architectural conventions. It establishes that platform-native deployment structure takes precedence over hand-authored repository layout assumptions.
